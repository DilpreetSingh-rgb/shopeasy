
SHOPEASY WEBSITE - SETUP GUIDE

1. Create a folder named ShopEasy.
2. Create these four files inside it:
   - index.html
   - style.css
   - script.js
   - README.txt

3. Copy the code into the matching files.
4. Save all files.
5. Double-click index.html to open the website in your browser.

HOW TO USE

- Click Manage Store.
- Change your store name and phone number.
- Add product categories.
- Add products with their prices and image URLs.
- Edit or delete existing products.
- Customers can click Order on WhatsApp.

IMPORTANT

- Products and categories are saved in browser local storage.
- Data stays in the same browser on the same device.
- This is a frontend demo, not a hosted online store.
- Real customer orders and shared inventory require a backend.
